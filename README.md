# super-mario-bros-allegro5-recreation
A custom 2D game engine built from scratch in C++ using Allegro 5, includes 2-player simultaneous mode. Hope you enjoy it! 
# Project overview and motivation
This project was developed over **2 months of intensive, autonomous development** serving as a personal tribute to the roots of gaming-a passion that started since I was a kid. 
The main challenge was to recreate Super Mario Bros with the style of SNES not relying on commercial game engines, every single subsystem (rendering loops, gravity physics, sound routing, and collision detection) was created from the ground up using raw C++ and the Allegro 5 multimedia library.
